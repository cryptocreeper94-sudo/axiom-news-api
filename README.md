# Axiom42 News API

> **Live:** [api.axiom42news.com](https://api.axiom42news.com)  
> **Author:** Andrews, Ronald Jason — DarkWave Studios LLC

---

## Overview

Backend API service for the Axiom42 News platform. Handles news aggregation, deterministic article rating, storage, and API endpoints consumed by the Axiom42 News frontend.

## Endpoints

Serves the Axiom42 News frontend with:
- News article aggregation and caching
- Deterministic rating computation
- Source quality analytics
- Article search and filtering

## Development

```bash
npm install
npm run dev
```
